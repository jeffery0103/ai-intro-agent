# 課程介紹:Python 程式設計入門(115-2)

- 課號:EG 9998
- 授課老師:陳測試 老師
- 學分:3
- 上課時間:星期二 第 2–4 節
- 課程內容:從零開始學 Python,包含變數、迴圈、函式與排序演算法,期末完成一個小專題。
